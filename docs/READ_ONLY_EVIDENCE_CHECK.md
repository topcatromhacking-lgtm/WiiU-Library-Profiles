# v1.3.2: Reproduce the report and single-backup reconciliation

This is a **read-only PC-side evidence checker**, not a Wii U deployment tool. All console reports and SD saves remain private on the owner's PC. The public repository contains only code and synthetic unit tests.

## Inputs

Use the existing exact four files generated by v0.8.1 and v1.3.2 diagnostics, plus the backed-up SD Barista file:

- `Barista-copy1.dat`: **one** powered-off backup of the candidate SD Barista account save
- `v132-barista-attest.csv`: the read-only v1.3.2 attestation
- `v132-fixed-icons.csv`: exactly 15 protected icon entries with IDs and record types
- `v08-menu-report.csv`: v0.8.1 Menu filter report

Run from repository root:

```sh
python src/v132_readonly_evidence.py \
  --barista /private/Barista-copy1.dat \
  --attestation /private/v132-barista-attest.csv \
  --fixed-icons /private/v132-fixed-icons.csv \
  --menu-report /private/v08-menu-report.csv
```

No output is written. Console-specific Title IDs, SHA-256 hashes, and paths are **not printed**. Return code 0 means the four artifacts reconcile. A contradictory input is refused and exits nonzero. The tool has no ability to write Barista saves or lists.

- Only one independently verified powered-off backup is available. Do not claim the formal two-backup transaction gate passed.
